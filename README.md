# CPP-Program
This project is a user-interface to help a grocery strore track twhich produce is being sold the most. It reads an input file that has all produce sales. The interface gives the user 3 options; search a specific item to report how many were sold, list all of the items and how many were sold with a numeric value, or list all of the items and how many were sold via histogram.
I used OOP to simplify the code. I created a class for the grocery items, that indexs an existing produce item or creates a new item. I like this approch, because the code can be easily modified if the format of the input file completely changes. 
One improvement I wanted to make, but fell short of time was making the "full list" options 1 function. A boolean variable would then be used to determine if the output was numeric or histogram.
I think the most challenging part was trying to figure out how I wanted to tie everything together. The coding wasn't too difficult, I just took it one task at a time.
I recently started working on an idea I have for a game. In this project, I read a file to create class objects, and I am going to do the same in my game. I'm sure there are better ways to handle save files for games, but I find trying to figure out my own methods before learning the right way, helps me really understand the "why".
I mentioned earlier that I used OOP to make the program more adaptable if the input file changes, but I also made it easy to change the filename and file location of the input file if the customer needs to adjust that. A big improvement would have been creating an option for the user to change this, but...time.
